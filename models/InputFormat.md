# Model Input Format

## 输入

| 项 | 值 |
|---|---|
| 名称 | `images` |
| 形状 | `[B, 3, 640, 640]` |  输入分辨率为：640*640
| 类型 | FP32 |
| 布局 | NCHW |
| 颜色 | RGB |
| Batch | 1 / 4 / 8 |

源图可能是 600×600、1024×1024 等，统一处理后送入模型。

## 预处理

| 步骤 | 说明 |
|---|---|
| 1. Letterbox | 保持比例缩放到 640×640，空白居中填充 |
| 2. 颜色 | BGR → RGB |
| 3. 归一化 | `pixel / 255`，mean=0，std=1 |
| 4. 排布 | HWC → CHW，FP32 |

Letterbox：

```text
scale = min(640 / src_w, 640 / src_h)
```

不能直接拉伸到 640×640。

## 输出

| 项 | 值 |
|---|---|
| 名称 | `output0` |
| 形状 | `[B, 8, 8400]` |
| 类型 | FP32 |
| 内容 | 4 个 bbox 参数 + 4 个类别分数 |
| NMS | 模型内没有，C++ 侧处理 |

## 类别

| ID | 类别 |
|---:|---|
| 0 | D00 纵向裂缝 |
| 1 | D10 横向裂缝 |
| 2 | D20 网状裂缝 |
| 3 | D40 坑洞 |

## TensorRT Profile

| 项 | 形状 |
|---|---|
| min | `1×3×640×640` |
| opt | `4×3×640×640` |
| max | `8×3×640×640` |

## 注意

- 输入必须是 **RGB**，不是 BGR。
- 必须使用 **letterbox**，不能直接 resize。
- 检测框要按 letterbox 的 scale 和 padding 逆映射回原图。
